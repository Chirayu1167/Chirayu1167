BTech student, mostly self-taught outside the classroom. My projects so far cover authentication infrastructure, a voice assistant, and an NLP preprocessing platform, and I'm now expanding into computer vision and AI agent systems.

I tend to choose the version of a project with a few more moving parts, even when a simpler solution would work. Splitting Pay-Trust into multiple services instead of keeping everything in a single application was one of those decisions. I enjoy the parts of development where something breaks in a way the tutorial never mentioned — that's usually where I learn the most.

## Featured Projects

### [Pay-Trust](https://github.com/Chirayu1167/Pay-Trust)

OTP-based payment authentication platform built with FastAPI, WebSockets, and Twilio SMS verification. Designed as multiple services to explore real-time communication, authentication workflows, and deployment challenges across distributed components.

### [Phoenix AI Assistant](https://github.com/Chirayu1167/Pheonix-AI-Assistant)

Voice-first desktop assistant featuring wake-word detection, speech recognition, text-to-speech, and a custom GUI. Built with a focus on keeping the interaction pipeline responsive while minimizing reliance on external services.

### [Neurix](https://neurix-nlp-001bychirayu.streamlit.app/)

NLP preprocessing platform for cleaning, tokenizing, and structuring raw text for downstream analysis. Created as a reusable tool to streamline text preparation across multiple NLP workflows.
